Kebijakan Privasi

Terakhir diperbarui: 9 Oktober 2026

Kami merancang blog ini agar seminimal mungkin menyentuh datamu: tidak ada akun, tidak ada pelacakan iklan, tidak ada penjualan data.

1. Data yang kami kumpulkan

  • Hampir tidak ada. Membaca artikel tidak meminta nama, email, atau data pribadi.
  • Email newsletter/kontak. Formulir memakai mailto: — aplikasi email di perangkatmu yang mengirim pesan ke redaksi. Alamat dan isi pesan dipakai hanya untuk membalas/mengirim info yang kamu minta.
  • Token di browser-mu sendiri. Halaman /admin/ menyimpan token GitHub dan key Unsplash yang kamu masukkan sendiri di localStorage. Tidak pernah dikirim ke server kami, tidak masuk repo — hanya dipakai browser-mu untuk bicara langsung ke API GitHub/Unsplash.
  • Log teknis standar. Cloudflare (infrastruktur) dan GitHub (host kode) mencatat log standar (IP, waktu akses, halaman) untuk keamanan. Kami tidak menggabungkannya jadi profil individu.

2. Cookies dan pelacakan

Kami tidak memasang cookie pelacakan, analitik pihak ketiga, maupun iklan bertarget. Satu-satunya penyimpanan lokal adalah localStorage admin milikmu sendiri, yang bisa dihapus via tombol "Hapus" atau pengaturan browser. Gambar dari Unsplash CDN dan tautan keluar tunduk pada kebijakan masing-masing pihak ketiga.

3. Berbagi data

Kami tidak menjual, menyewakan, atau menukar data pribadimu. Email hanya dibagikan bila diwajibkan hukum atau untuk keamanan situs — seminimal mungkin.

4. Keamanan

Situs disajikan lewat HTTPS via Cloudflare. Meski begitu tidak ada sistem 100% kebal — jangan kirim data sensitif (KTP, bank) lewat kontak; untuk ternak sakit atau wabah, hubungi dokter hewan/dinas peternakan langsung.

5. Hakmu

Kamu berhak meminta salinan, koreksi, atau penghapusan korespondensimu — tulis lewat Kontak dari email yang sama. Target proses 7 hari kerja.

6. Anak-anak

Konten ditujukan untuk pembaca dewasa. Kami tidak sengaja mengumpulkan data anak-anak.

7. Perubahan kebijakan

Bila praktik data berubah (mis. menambah analitik/komentar), halaman ini diperbarui beserta tanggalnya.

8. Kontak privasi

Pertanyaan data pribadi: hubungi redaksi dengan subjek "Privasi".
