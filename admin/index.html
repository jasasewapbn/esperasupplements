Admin Blog (Git-based)

100% statis untuk Cloudflare. Token GitHub + key Unsplash hanya di browser (localStorage), tidak masuk repo. Buat token di GitHub → Settings → Developer settings → Personal access tokens → Fine-grained: pilih repo jasasewapbn/esperasupplements, izin Contents: Read and write.

Tanpa key pun bisa publish (artikel tanpa foto). Key tidak pernah masuk repo. Daftar gratis di unsplash.com/developers.

Cara kerja: admin membuat content/posts/<slug>.md + update content/index.json via GitHub API. Cloudflare yang tersambung via Connect to Git deploy otomatis 1–2 menit.
